Projeto: Views e Triggers com MySQL  
Este projeto demonstra o uso de views e triggers em um banco de dados relacional com base em um cenário empresarial.

Objetivos  
Criar views para consultas analíticas (departamentos, projetos, gerentes, dependentes)  
Simular permissões de acesso por tipo de usuário  
Simular triggers para remoção e atualização de dados  

Estrutura  
estrutura.sql: criação das tabelas e inserção de dados  
views.sql: criação das views solicitadas  
triggers.sql: simulação de gatilhos (delete/update)  
consultas.sql: comandos SELECT para visualizar os resultados
